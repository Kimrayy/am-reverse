Autentikasi API

Semua endpoint /api/* memerlukan API key rahasia melalui header. Jalankan request hanya dari backend atau worker milik Anda; jangan masukkan secret ke kode frontend, query string, atau aplikasi browser.

GET /api/stats HTTP/1.1
Host: domain-anda.com
X-API-Key: <API_KEY_RAHASIA>
AM_API_URL=https://domain-anda.com
AM_API_KEY=isi_kunci_rahasia_di_server

Endpoint

Gunakan base URL deployment Anda, lalu tambahkan path di bawah ini.

GET
/api/stats

Health check untuk mengetahui apakah aplikasi API merespons. Endpoint ini menggunakan respons dari /api/status lama, bukan data keberhasilan aktivasi.

curl -H "X-API-Key: $AM_API_KEY" \
  "$AM_API_URL/api/stats"
{
  "status": "online",
  "timestamp": "2026-10-15T08:00:00.000Z"
}
POST
/api/get-link

Meminta pengiriman email autentikasi melalui mekanisme pengiriman link yang sudah ada. Gunakan hanya untuk alamat email yang telah memberi persetujuan. Ini bukan konfirmasi pembayaran atau aktivasi premium.

curl -X POST "$AM_API_URL/api/get-link" \
  -H "X-API-Key: $AM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com"}'
{
  "success": true,
  "email": "user@example.com",
  "message": "link dikirim..."
}

404Path tidak ditemukan.

Integrasi verifikasi

Verifikasi yang aman harus menggunakan autentikasi pengguna yang sah serta bukti pembelian yang benar-benar valid. Jangan mengumpulkan magic link atau token sesi Firebase pihak ketiga melalui halaman reseller, dan jangan menafsirkan HTTP 200 sebagai bukti lisensi premium telah aktif.
